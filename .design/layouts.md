# PDOS: Layout & Editorial Rhythm

Our layouts should follow the composition rules of classic print publications.

## Layout Patterns

- **Newspaper Masthead**: Clean, centered headers with date, issue, and status lines.
- **Varying Cadence**: Alternating column spans (full-width image → 2-column text → 3-column grids).
- **Hairlines**: Use thin `1px` borders and separators to organize content rather than box shadows.
- **Pull Quotes**: Big, italic `Instrument Serif` blocks to break up reading sections.
- **Whitespace Anchors**: Let elements sit inside generous padding rather than filling the entire container.
