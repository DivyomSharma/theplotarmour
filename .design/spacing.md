# PDOS: Spacing Tokens & Scales

Everything must breathe. Spacing should follow a strict, generous layout scale.

## Spacing Scale

- **Micro padding**: `8px` / `16px` (labels, small offsets)
- **Item gap**: `24px` (between title and description)
- **Card padding**: `32px` – `40px` (internal padding for content cards)
- **Grid gap**: `32px` – `48px` (gutters between columns)
- **Block margin**: `64px` – `96px` (spacing inside page layouts)
- **Hero top**: `120px` – `160px` (distance from top navigation)
- **Section gap**: `140px` – `200px` (whitespace between major sections)

## Spacing Rule
If in doubt, increase the spacing by 2×. Never stack section containers immediately after each other without hairline separators and block padding.
